# go-economics

경영 의사결정에 쓰는 경제학을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 미시·게임이론·산업조직, 거시·통화·재정, 국제경제, 행동경제학, 경제 통계 읽기를 다룹니다. 한국은행·공정거래위원회·국가통계 같은 국내 제도를 뼈대로 하고, 연준·ECB·IMF 같은 해외 기준과 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식과 실제 통계를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다. 금리·물가 같은 수치와 법 조문은 튜터가 그때그때 공식 출처에서 확인하고 출처를 붙입니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), [Claude Code](https://code.claude.com) 또는 Claude Desktop(Claude 계정으로 로그인)입니다. 비공개 리포이므로 리포 관리자에게 GitHub 초대를 요청해 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다. 계산은 채팅·HTML 페이지·평소 쓰는 스프레드시트로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-economics
```

**Claude Code**

```bash
cd ~/Desktop/go-economics
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-economics` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 어떤 일을 하는지, 경제 공부 경험은 어떤지 짧게 묻고, 데이터·미시·거시 영역마다 내 업무에 맞춘 문제를 하나씩 풀어 출발점을 찾습니다. 경제가 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 현장 경험이 많아도 개념 문제로 한 번 확인합니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답과 실제 통계를 반영한 HTML을 만들어 가며 익힙니다. 통계표 일부는 튜터가 준 링크를 내가 직접 열어 읽습니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

마지막에는 가격 결정 메모, 거시 환경 브리핑, 정책·규제 영향 분석서 중 하나를 실제 업무용 초안으로 만듭니다. 재무·전략·세무처럼 다른 go-* 워크스페이스가 깊게 다루는 주제는 연결만 짚고 그쪽을 안내합니다. 투자·법률 자문은 하지 않습니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내가 만든 표·메모. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 표·메모를 쓰고, 웹(공식 통계·법령 사이트)을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고치거나 명령을 실행할 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 회사 기밀이나 개인정보는 대화에 넣지 마세요. 내 사업 숫자를 예로 쓰고 싶으면 대략의 값으로 말해도 충분합니다.
